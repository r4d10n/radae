6. NEXT STEPS
================================================================================

To use this layer:

1. Add to Yocto build system:
   bitbake-layers add-layer /home/user/radae/meta-radae

2. Configure local.conf:
   MACHINE = "imx8mp-radae"
   DISTRO = "radae-distro"

3. Add recipes to each recipes-* directory

4. Build and test:
   bitbake core-image-minimal
